# NextJS - React Refresher

## Learning Objectives

- Get an overview about what react is
- Learn the JSX syntax
- Learn how to use JSX to create react components
- Learn how to use props to pass data to react components
- Learn how to use state in react components to make UI elements reactive

## Overview

Next.js is a fullstack framework that uses React as its rendering engine. Therefore, it is crucial to have a basic undestanding of React for this module. This unit is totally optional and, given the time available, covers only the essentials. Use it as a refresher, or skip it if you feel already comfortable with React.
