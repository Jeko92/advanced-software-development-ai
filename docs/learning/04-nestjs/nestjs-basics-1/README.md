# NestJS Basics 1

This session introduces NestJS as a structured Node.js framework that enforces
architecture through TypeScript decorators and dependency injection. Students
learn what decorators are, how inversion of control works in NestJS, and how to
read a minimal application consisting of one module, one controller, and one
service.
