# NestJS Auth

This session covers authentication and authorization in a NestJS REST API using JSON Web Tokens and Passport.js. Students implement a full auth module that issues signed JWTs on login, protects routes with guards backed by a JWT Passport strategy, and exposes a `@Public()` decorator for endpoints that should remain open.
