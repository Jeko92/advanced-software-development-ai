# Software Design CS Fundamentals

This session is a breadth-first survey of three computer science foundations
relevant to backend development: data structures (linked lists, stacks, trees),
algorithms and complexity using Big O notation, and software architecture
patterns (monolith, microservices, serverless, layered). The goal is to build
trade-off reasoning and shared vocabulary rather than exhaustive theoretical
coverage.
