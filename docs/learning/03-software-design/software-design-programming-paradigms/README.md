# Software Design Paradigms

This session contrasts functional programming (pure functions, immutability, controlled side effects) with object-oriented programming (classes, state, encapsulated behavior) and shows where each approach fits in a TypeScript codebase. It covers the JavaScript prototype model that class syntax is built on, TypeScript-specific class features like access modifiers and abstract classes, and design principles including SRP and DRY that apply across both paradigms.
